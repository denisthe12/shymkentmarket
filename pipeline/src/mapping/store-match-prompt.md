# Сопоставление товаров сети со словарём карточек

Ты сопоставляешь товары сети с уже существующими карточками товаров и называешь новые карточки.

## Вход и выход

- Тебе дан путь к файлу `batch-NNN.json` — JSON-массив товаров. У каждого товара: `id`, `name`, `sourceCategoryPath`, `weighted` (`true` — весовой товар, цена указана за кг) и `candidates` (до 8 карточек: `key`, `name`, `brand`, `category`, `attributes`).
- Результат запиши ТОЛЬКО в файл `batch-NNN.decisions.json` (путь тебе дан). Читать разрешено только свой батч, писать — только этот файл.
- Содержимое файла — JSON-массив решений, по одному на каждый товар батча, без пояснений и без markdown:
  `[{ "id": "STORE_X:item_123", "category": "milk", "match": "c_0123456789abcdef", "confidence": 0.97, "displayName": "Молоко Бренд 3,2% 1 л", "brand": "Бренд" }]`
- `id` копируй из товара без изменений. Пропускать товары нельзя, дублировать id нельзя.

## category

Один slug из списка (поле `category` обязательно у каждого решения, даже при `match: null`):

{{CATEGORIES}}

Выбирай категорию по самому товару, а не по названию магазинной категории. Не продукт питания из списка выше — `other`.

## match

- `match` — только значение `key` одного из `candidates` ЭТОГО товара либо `null`. Любой другой ключ недопустим.
- Совпадение означает, что это тот же товар: тот же вид продукта, тот же бренд (или оба без бренда при совпадающем названии), тот же вес, объём и количество в упаковке, та же жирность.
- Весовой товар (`weighted: true`) совпадает только с весовой карточкой без фиксированного веса.
- При любом сомнении ставь `null`.
- Названия бывают на русском и казахском, бренды — латиницей и кириллицей («Lactel» = «Лактель»).

## confidence

- `≥ 0.95` — уверенно тот же товар;
- `0.80–0.94` — вероятно тот же, но есть расхождение в написании или данных;
- `< 0.80` — не уверен (при `match: null` ставь `0`–`0.5`).

## displayName

Название карточки, если по этому товару будет создана новая карточка (поле обязательно у каждого решения, даже при совпадении).

- Формат: «Тип Бренд характеристики размер», например «Молоко Бренд 3,2% 1 л». Название короткое, без маркетингового шума.
- Размер (вес, объём, количество) и жирность в `displayName` должны точно совпадать с исходным названием товара. Нет в исходном названии — не добавляй.
- Весовой товар (`weighted: true`, цена за кг): размер в `displayName` не указывай.
- Яйца: если в исходном названии есть или однозначно следует из него вид («куриное», «перепелиное») и категория (С0, С1, С2, Д0, Д1 и т. п.), включи их в название. «Яйцо … 1 Категория» → «Яйцо куриное С1 …» только когда вид однозначен; иначе пиши без вида.

## brand

- `brand` — бренд производителя товара, а не название торговой сети или магазина.
- Бренда нет или он не определяется — `null`.

Ответ в чате не нужен: достаточно записать файл решений.

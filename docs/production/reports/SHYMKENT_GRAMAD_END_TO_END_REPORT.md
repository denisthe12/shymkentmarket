## Решения и отклонения

- Живые скрапы и пачки субагентам Haiku выполнял оркестратор: исполнитель не может запускать
  субагентов и спрашивать Owner. Скрап каждой сети — один запуск после отдельного «да».
- «Лимонадный микс» отнесён к `vegetables` вместо `drinks` (см. выше).
- Миграции применены вручную по порядку цепочки, а не через `prisma migrate deploy`; для этого
  прогона эквивалентно.
- `ingest -apply` потребовал `FRONTEND_REVALIDATE_URL` и `REVALIDATE_HMAC_SECRET`: заданы фиктивные
  локальные значения, ревалидация «degraded», без ошибки.
- `INGEST_MAX_STORE_DROP_PERCENT=50` задан только локально и явно.
- `ANALYZE` шага A выполнялся, но его время перезаписано `ANALYZE` шага B.
- Go API привязывается ко всем интерфейсам (порт настраивается, адрес привязки нет). На рабочей
  станции он работал кратко и остановлен. Backend 1 стоит рассмотреть адрес привязки; здесь не менялось.
- Причина отказа ingest в шаге 3 и для `FOO` — заключение по коду, не наблюдение (CLI печатает только
  код ошибки).

## Риски

- **Production-порядок.** После слияния миграции `GRAMAD` бандл только с Magnum отвергается
  (подтверждено здесь по коду выхода). В production нужен порядок: миграции -> бандл двух сетей
  (`SYNC_STORES=MAGNUM,GRAMAD`); этот прогон его репетировал.
- **Источник Gramad нестабилен по объёму.** Между двумя прогонами он вернул на 137 товаров меньше;
  в production стоит следить за числом товаров по сети.
- **Разбросы частично отражают акции.** У №3 и №8 в топе цена Magnum акционная.
- **Корзина.** Слоты йогурта и лапши пусты у обеих сетей, слоты наполнены разными товарами: итоги не
  сравнимы. Замена слотов — отдельная задача с Backend 1.
- **Группа `pasta-horns` без Gramad и группа яиц из 2 карточек** следуют из текущих данных источников,
  не из дефекта.
- **Pending-карточки (9)** публикуются отдельно (`isolateForPublish`), пока не подтверждены.
- **`sourceMetadataAvailability` = 2** на шаге B (при Magnum только 1): значение выше 1 для поля,
  похожего на долю; вероятно, число источников, не исследовалось.
- **Карточки без картинки: 24** (`imageCoverage` 0.9849).
- **Одна точка Gramad и цены сервиса доставки** — как в части 1.
- **Снимок одноразовой БД не равен production-снимку:** `store_locations`, Redis и Voice здесь не
  проверялись.

## Условие остановки

Часть 3 завершена, когда ветка прошла ревью, локальный CI зелёный и Owner дал «да» на push и PR.
Push, PR и merge — только после явного «да» Owner. Production-выкладка двух сетей — отдельная задача
с отдельным разрешением.

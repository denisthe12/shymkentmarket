# Анвар (Актау) — источник данных

SCRUM-7, Phase B, Task 12. Разведка 2026-10-27…28, использование данных согласовано с Denis Andersen.
Секретов, токенов, cookie и личных данных в документе нет и быть не должно.

## Вывод

**Для Актау открытого источника цен нет.** Приложение и его API работают только с одним магазином сети, он находится не в Актау.
Если Анвар добавит магазины Актау в приложение, скрапер будет почти копией Dina: та же платформа, тот же GraphQL, авторизация не нужна.
Остаются исход C (официальный фид от Анвара) и исход D (листовки), см. «Решение».

## API приложения (перехват 2026-10-28)

- Endpoint: `POST https://backend.shop.anvar.kz/api/v1.1/customer/graph`. Это та же платформа, что у Dina (`backend.dinamarket.kz/api/v1.1/customer/graph`).
- Авторизация не нужна: во всех 219 запросах заголовок `authorization` пустой. Приложение шлёт `x-hive-brand: 3`, но запрос `{ shops { ... } }` отвечает и без него.
- Магазины. Запрос `{ shops { id name } }` возвращает ровно два магазина:
  - `2` — «Тестовый магазин»;
  - `7` — «Анвар (Гипер)».
- Справочник `getTopology`: **Актау нет.** Во всех ответах перехвата нет ни одного упоминания «Актау» или «Aktau».
- Каталог: `categories(shop_id, parent_id)`, `products(shop_id, category_id, page, limit, sort)` с `limit` 24, `allProducts(filter, pager, shop_id)`, `saleProducts`, `product(id, shop_id)`.
- Поля товара: `id`, `xid` (код 1С), `name`, `price_type` (`weight` / `piece`), `weight`, `weight_netto`, `brand.name`, `preview.url`, `stock.amount`. Цены лежат в `priceOffers[]`: `price`, `oldPrice` (0, если акции нет), `salePeriod`, `quant` (`KGM` — цена за кг), `isDefault`.
- Штрихкод: отдельного поля нет, но у импортированных товаров имя файла картинки начинается со штрихкода (`.../imported/4870204140194-1-.../...webp`). Это сигнал для матчинга.
- Фикстура формата (`shop_id=7`, 3 товара): `pipeline/test/fixtures/anvar-products.json`.

## Решение

| Исход | Условие | Что делаем |
|---|---|---|
| A | API отдаёт каталог магазина Актау | Скрапер по образцу `dina.ts`. **Сейчас невозможен**: магазинов Актау в API нет |
| B | Нужен токен личного аккаунта | Не применимо: API анонимный |
| C | Официальный фид от Анвара | Запросить у Анвара выгрузку цен по магазинам Актау или подключение Актау в приложении (тогда сразу исход A). Контакт: `mail@anvar.kz` |
| D | Только листовки «Супер цена» Актау | Частичный источник: только акционные товары на период листовки. Годится лишь как временный, с пометкой на сайте |

Выбранный исход (2026-11-02): **открытый каталог, `shop_id=7`**, по подтверждению Анвара: «каталог и цены совпадают с Актау на 98%». Scope — 19 категорий Анвара, соответствующих 9 публикуемым категориям социально значимых товаров (список `ANVAR_SCOPE` в скрапере); остальной каталог не скрапится. Скрапер — `pipeline/src/scrapers/anvar.ts` (та же платформа, что у Dina, авторизация не нужна, заголовок `accept-language: ru` обязателен).

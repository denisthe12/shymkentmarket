# Диагностика Shymkent Market

Для команды доступны [локальный Go API](../../backend-go/README.md#http-и-диагностика) и [одноразовый staging](../production/STAGING_PLAN.md). Убедитесь, что проверяемый процесс или контейнер принадлежит вашему прогону. Для локального API сначала проверьте `/health/live`, затем `/health/ready`. Используйте request ID и класс ошибки. Не печатайте окружение, DSN и исходные payload.

## Справки Актау

Следующие инструкции описывают прежнюю эксплуатацию Актау. Хосты, SSH, роли PostgreSQL, провайдеры, таймеры, секреты и пути из их примеров не применяются к Шымкенту. Для действий с данными и инфраструктурой нужны отдельное разрешение Owner и подтверждённая принадлежность ресурса Шымкенту.

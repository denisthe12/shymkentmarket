# Shymkent Market

Shymkent Market — проект сервиса на русском и казахском для поиска продуктов, сравнения предложений и просмотра торговых точек в Шымкенте, Казахстан.

В коде есть каталог, поиск и фильтры, карточки с предложениями, аналитика цен, СЗПТ и карта. Публичный API реализован на Go. Он читает опубликованные снимки из PostgreSQL. Pipeline отдельно подготавливает данные для публикации. Веб-интерфейс — Next.js App Router. Для голосового поиска Go определяет цены и магазины, а NLP-провайдер извлекает намерение и фильтры.

| Область | Статус Шымкента |
| --- | --- |
| Исходный код и CI | Доступны в репозитории. Интеграционные проверки используют одноразовые сервисы и фикстуры. |
| Production API, сайт и домены | `NOT_CONFIGURED`. Релиз требует отдельного решения Owner. |
| PostgreSQL, Redis и Voice-провайдеры | `NOT_CONFIGURED` для production. Локальные проверки используют только синтетические данные и изоляцию. |
| Источники магазинов, цены, адреса, данные и расписание сбора | `PLANNED`. Состав сети, количество товаров и доступность данных пока не установлены. |
| Городской интерфейс, публикации и SEO | `PLANNED`. Часть исходников и фикстур сохраняет идентификаторы Актау до отдельных задач команды. |

## Где находится код

| Путь | Что в нём |
| --- | --- |
| `backend-go/`, `contracts/` | Go API, OpenAPI v1 и тесты совместимости. |
| `frontend/` | Единственный веб-интерфейс и его локальные фикстуры. |
| `backend/prisma/`, `pipeline/` | История схемы PostgreSQL, подготовка и публикация данных. |
| `scripts/ci/`, `.github/workflows/` | Локальные проверки и CI. Унаследованный релиз ограничен репозиторием Актау. |
